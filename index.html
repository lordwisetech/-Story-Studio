Step-by-step guide
  1. 📂 Import HTML story (Studio tab): choose your story file. Wait for "Ready: N scenes found".
  2. Cartesia key (Voice tab): paste it. With "Remember my key" ticked it is saved and filled in next time. 💾 Save key to text file downloads cartesia-key.txt; 📂 Load key from file reads it back; 🗑 Forget key deletes it from this device.
  3. 🔑 Test API key & load voices: must show a green tick. ▶ Test plays a sample. Narrator / Male / Female choose which voice is used for each role (optional, automatic otherwise).
  4. Video quality (Studio tab): select it BEFORE Start & Record. Full HD for YouTube, Vertical for Reels/TikTok, 720p if your laptop is slow.
  5. Pace: set before Start. Higher means shorter gaps between scenes. Voice speed never changes.
  6. Auto-sync: ON fits scene animation to each voice line. Toggle before Start.
  7. Record video while playing: untick to only watch the story without making a file.
  8. ▶ Start & Record: first generates all voices (wait for the progress text), then plays and records. Keep this tab open and visible until it says "Video ready".
  9. ⬇ Download video: turns on when the story ends. You get a .webm file; use CapCut or a converter for MP4.
  10. ↻ Reset: reloads the story so you can change quality or pace and record again.
  11. Prompt tab: type the title and story, then 📋 Copy prompt and give it to Claude to make a new story file.
  1. Make the story file: in the Prompt tab type your title and story, copy the prompt, and give it to Claude. You get one HTML file.
  2. Import it in the Studio tab. The app reads its list of scenes (beats).
  3. Voice: every line is generated with Cartesia before you press Start, so nothing waits or stutters during the video.
  4. Auto-sync: the app measures each voice line and stretches or compresses that scene's animation to fit it exactly. A scene ends when its voice ends, then the next one starts.
  5. Record: picture, subtitles, voice, music and sound effects are recorded together at your chosen quality (up to 1080p).
  6. Keep this tab open and visible while it records. The app also asks your device not to sleep.
  7. Download appears when the story ends. It is a .webm file; CapCut or any converter can turn it into MP4.
Host it yourself: Cartesia calls and file downloads are blocked inside claude.ai published pages, so save this file and open it locally (through http://localhost is safest) or upload it to your own site.
